# Strona Cw-El Client (HTML, CSS, JS)

Pliki: `index.html`, `style.css`, `script.js`, `logo.png`, `favicon.png`. Bez budowania, bez bibliotek.

## Ustaw przed publikacją
W `script.js` na samej górze zmień `CFG.download` na link do instalatora (np. `https://github.com/TWOJ-LOGIN/cw-el-client/releases/latest`).
Dopóki zostaje `TWOJ-LOGIN`, przycisk „Pobierz” prowadzi na Discorda.

## GitHub Pages
1. Utwórz repozytorium i wgraj te pliki do głównego folderu.
2. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.
3. Strona będzie pod `https://TWOJ-LOGIN.github.io/NAZWA-REPO/`.

## Co jest w środku
- Ekran startowy z moda narysowany na canvasie: najedź na menu, kliknij logo pięć razy (party). „Cw-El Moduły” przewija do sekcji z modułami.
- Przełączniki modułów sterują podglądem HUD.
- PL i EN (język z przeglądarki, przycisk w nagłówku).
- Motyw Halloween włącza się sam 20 X – 2 XI (albo `?halloween` w adresie), tak jak w launcherze.
